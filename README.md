# ПР №5. Строки, массивы, циклы и методы обработки данных

Абраменков Андрей, группа ЭФБО-12-25. Вариант 1.

Программа разбирает строку табеля за рабочую неделю (`8;9;10;8;8`), проверяет её и считает показатели:
сумму, среднее (по варианту 1 — медиану), дни с переработкой, недельную переработку и уровень продуктивности.

## Сборка и запуск

Требуется Java SE 21 или выше (`java -version`).

```
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr02.SelfCheck
```

Windows: запустить `run_selfcheck.bat` (он включает UTF-8, собирает и запускает проект).

`SelfCheck` последовательно выполняет unit-проверки, прогоняет `data/sample.csv`, затем переходит
в интерактивный режим: вводите строки табеля, выход по `exit` или пустой строке.

## Структура

- `src/ru/edu/pr02/TimesheetAnalyzer.java` — бизнес-логика (6 статических методов)
- `src/ru/edu/pr02/SelfCheck.java` — точка входа: unit-проверки, data-driven режим, интерактив
- `data/sample.csv` — контрольные значения
- `diagrams/` — `activity.dot/png`, `class.dot/png`
- `DECISIONS.md` — решения и ответы на вопросы
- `REPORT.docx` — отчёт
